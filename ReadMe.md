# HyperNetSuite

HyperNetSuite is a proposed set of terminal and command-line clients for
[HyperNet](https://github.com/Federated-Industrial-Laboratories/HyperNet).

The project is in design. This repository does not yet provide runnable clients
or a production security guarantee.

The intended clients support network enrolment, pages, publication review,
mailboxes, file exchange and explicitly authorised service connections. They use
the same documented interfaces available to other applications.

See [Requirements](Documentation/Requirements.md) for the intended contracts.
